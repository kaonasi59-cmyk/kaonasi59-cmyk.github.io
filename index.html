About GALAXY AI Bot · English

GALAXY AI Bot is Anton’s personal Telegram assistant for tasks, reminders, daily summaries and viewing events from selected Google calendars. It calculates available time between 10:00 and 23:00 Europe/Moscow. Access is restricted to the project owner; there is no public sign-up.

Google Calendar access uses OAuth and the calendar.readonly scope. The integration does not create, edit or delete Google Calendar events. Apple Calendar is not currently connected. This website is informational and does not display private calendar data.

Политика конфиденциальности

Обновлено: 3 октября 2026 года. Относится к персональному проекту GALAXY AI Bot и его интеграции Google Calendar.

Какие данные используются

После разрешения владельца приложение читает сведения о выбранных календарях и событиях: идентификаторы, названия, даты и время, часовой пояс и признаки занятости. Для подключения сохраняются OAuth-токены и параметры клиента. Пароль Google приложению не передаётся.

Зачем нужны данные

Сведения используются для показа расписания, расчёта свободных промежутков, персональных сводок и ответа на запросы владельца. Коллектор обновляет календарный кэш примерно каждые пять минут; рабочее окно кэша — текущий день и следующие семь дней.

Где хранятся данные и кому передаются

Токены и календарный кэш хранятся на сервере GALAXY с ограничением доступа средствами операционной системы. Система резервного копирования может сохранять эти данные в зашифрованных копиях, включая облачное хранилище Яндекс Диска.

Расписание и сводки отправляются владельцу через Telegram. При обработке запросов персональным AI-ассистентом сведения о ближайших событиях могут передаваться используемому проектом поставщику AI для формирования ответа. Данные передаются сервисам лишь в объёме, необходимом для этих функций. Названия событий рассматриваются как внешние данные, а не как команды для ассистента.

Данные Google не продаются, не используются для рекламы и не используются проектом для обучения общих AI-моделей. GALAXY AI Bot соблюдает Google API Services User Data Policy, включая требования Limited Use: политика Google.

Хранение, удаление и отзыв доступа

Рабочий кэш заменяется при успешной синхронизации. Токены хранятся до отключения интеграции или удаления владельцем. Старые резервные копии могут содержать предыдущие версии данных до их удаления по действующей политике хранения резервных копий.

Владелец может отозвать разрешение в настройках подключений Google. Отзыв блокирует дальнейший доступ, но сам по себе не удаляет серверный кэш и резервные копии. Для удаления сохранённых данных, токенов и связанных копий следует обратиться по адресу ниже; запрос обрабатывается владельцем проекта.

Privacy policy · English

With the owner’s consent, GALAXY reads selected Google calendars and event identifiers, titles, dates, times, time zones and availability flags. OAuth tokens and client configuration are stored; the app never receives the Google password. Data is used to display schedules, calculate free time, produce personal summaries and answer the owner’s requests.

Tokens and calendar cache are stored on the GALAXY server with restricted operating-system access. The cache covers today and the next seven days and is refreshed approximately every five minutes. Encrypted backups may include this data and may be stored on Yandex Disk.

Schedules and summaries are delivered to the owner through Telegram. Information about upcoming events may also be sent to the project’s AI provider to answer the owner’s requests. Service providers receive data only as needed for these features. Google data is not sold, used for advertising or used by the project to train general-purpose AI models. GALAXY complies with the Google API Services User Data Policy, including Limited Use.

The working cache is replaced after a successful sync. Tokens remain until the integration is disconnected or the owner removes them. Previous data may remain in backups until those backups are deleted under the backup retention policy. Access can be revoked through Google Account connections. Revoking access stops future API access but does not automatically remove stored cache or backups. Contact the project owner below to request removal of stored data, tokens and associated backups.

This informational site contains no sign-in forms, analytics counters or advertising trackers. GitHub Pages hosts it and may process technical visitor data under GitHub’s privacy statement. Last updated: October 3, 2026.
